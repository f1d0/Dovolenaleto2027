# Dovolená léto 2027

Přehled ubytování pro společnou dovolenou sedmi rodin, týden 31. 7. – 7. 8. 2027.

Stránka je **zamčená heslem** — obsah je zašifrovaný (AES-256-GCM, klíč odvozený
přes PBKDF2), takže ani ve zdrojovém kódu není čitelný. Heslo má Filip.

`index.html` je generovaný soubor. Zdrojový kód a data žijí v soukromém repozitáři.
